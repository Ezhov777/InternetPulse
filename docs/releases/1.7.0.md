# Internet Pulse 1.7.0

Continuous Speedtest for macOS and Windows 11.

- Five interface languages: Russian, English, French, German and Spanish.
- Grouped numbers, decimal MB / GB / TB, localized dates.
- Ten checked download endpoints each for the UK, US, France, Germany and Spain; Russian presets retained where reachable. Search by country and name.
- Native self-contained Windows 11 x64 build. Developer tools are not needed to run either app.
- Save daily history every 10 seconds and when stopping/exiting.
- Show no-data status and write the test outcome to the log.
- Internet Pulse branding and version in the window title.
- Translated documentation, native-view demo screenshots and chart animation.

## Download

- `InternetPulse-1.7.0-macos-arm64.zip`: macOS 14+ on Apple Silicon.
- `InternetPulse-1.7.0-win11-x64.zip`: Windows 11 x64, extract the entire folder and run InternetPulse.exe. .NET is included.

Close the older app before replacing it. macOS is ad hoc signed without Apple notarization; Windows is not Authenticode-signed. Checksums accompany the archives.

Windows validation covers loopback integration tests and automated WPF startup/close on a GitHub-hosted Windows runner; separate hands-on Windows 11 verification has not been performed. Third-party server availability depends on the route and time.
