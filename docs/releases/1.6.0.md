# Internet Pulse 1.6.0

Бесконечный Speedtest с новым названием, обновлёнными градиентами и встроенной историей изменений.

Новое:
- Приложение переименовано в Internet Pulse.
- Больше воздуха между иконкой и названием.
- Мягкие фиолетово-розовые и бирюзовые градиенты.
- Окно «Что нового» доступно из приложения и меню.
- Кнопка проверки обновлений сравнивает версию с последним опубликованным релизом GitHub.
- Версия и номер сборки синхронизированы с релизными файлами.

Сохранены многопоточность, независимые лимиты, режим «На максимум»,
рекорды сессии, таймер, дневная история и CSV.

Скачайте InternetPulse-1.6.0-macos-arm64.zip. Перед запуском закройте предыдущую версию.
Текущая сборка: macOS 14+ и Apple Silicon. Windows 11 — в планах.
Подпись ad hoc, без Developer ID и нотариализации Apple; другой Mac может
заблокировать первый запуск. Проверка ZIP: файл SHA256SUMS.txt.
