# Подготовленные данные для GitHub

Название репозитория: **InternetPulse** (или `routerpulse`).

Описание для поля About:

> Continuous internet speed tester: download/upload limits, parallel streams, live charts and daily traffic history. Windows 11 planned.

Темы: `speedtest`, `macos`, `swiftui`, `network-monitoring`, `bandwidth`, `internet-speed`.

Первая версия: **1.6.0**. Тег: **v1.6.0**. Лицензия: **MIT**.

## Публикация

GitHub Projects — это доски задач. Код нужно разместить в отдельном репозитории,
а приложение для скачивания — в его разделе Releases. Projects можно добавить позже.

1. Создайте пустой репозиторий InternetPulse в нужном аккаунте GitHub.
2. Загрузите содержимое этой папки в корень репозитория, включая `.github`.
   Не добавляйте папку `build`, `dist`, пользовательские CSV или старые архивы.
3. Запустите workflow **macOS build and test**, убедитесь в успешном результате.
4. Создайте тег `v1.6.0`. Workflow подготовит черновик релиза с ZIP и SHA-256.
5. Проверьте описание и файлы в черновике и опубликуйте его.

Готовый локальный ZIP и SHA-256 также можно вручную приложить к первому
релизу. Текст релиза: [releases/1.6.0.md](releases/1.6.0.md).

Исходники следует добавлять через Git, GitHub Desktop или веб-интерфейс.
Не загружайте один ZIP с исходниками вместо содержимого репозитория:
GitHub Actions и отображение README в таком случае не заработают.

## Локальный Git

В комплекте подготовлены файлы `.gitignore` и `.gitattributes`. При использовании
Git выполните обычные `git init`, `git add` и `git commit`, указав свою авторскую
информацию. Затем добавьте адрес созданного репозитория как `origin` и отправьте
ветку `main`. В комплект не включены пользовательские Git-настройки или учётные данные.
