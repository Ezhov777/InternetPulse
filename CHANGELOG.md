# Changelog

## 1.7.0 — 2026-10-29

- macOS и самостоятельная Windows 11 x64 сборка.
- Русский, английский, французский, немецкий и испанский; локализованные числа и даты.
- Разделители тысяч, МБ / ГБ / ТБ, совместимость истории предыдущих версий.
- Каталог серверов по странам и поиск, проверка актуальности тестовых файлов.
- Сохранение истории каждые 10 секунд и при остановке/выходе.
- Статус отсутствия данных и итог теста в журнале.
- Название Internet Pulse и номер версии в заголовке окна.

## 1.5.0

Первый подготовленный выпуск для GitHub, основанный на локальной версии 1.5.

### Возможности

- Непрерывная одновременная загрузка и отдача через HTTP.
- Независимые лимиты и режим максимальной скорости.
- Выбор 1, 4, 8 или 16 потоков на направление.
- Масштабируемый график, просмотр замеров и рекорды сессии.
- Обратный отсчёт, непрерывный таймер, история по дням и CSV.
- Каталог из 12 тестовых серверов и свои адреса.

### Подготовка проекта

- Версия и номер сборки вынесены в отдельные файлы.
- Добавлены воспроизводимая сборка, упаковка, SHA-256 и GitHub Actions.
- Добавлены README, лицензия MIT, документация и план Windows 11.
- Сборка очищена от локального режима до роутера и зависимости iPerf3.
- Защищено завершение сетевых потоков при одновременных запросах остановки.

### Ограничения

- Только macOS 14+ на Apple Silicon.
- Подпись ad hoc, без Developer ID и нотариализации.
- Скорость и доступность сторонних серверов не гарантируются.
